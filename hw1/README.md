# Домашнее задание для лекции по теме "Кооперативная многозадачность"

Реализован обход графа в глубину (DFS) с использованием кооперативной многозадачности без использования потоков.

## Поддерживаемые сущности

-   `Task` -- единица кооперативной задачи, выполняемая пошагово
-   `Scheduler` -- планировщик задач, реализующий выполнение в стиле LIFO (стек)

## Особенности реализации

-   кооперативная модель (задачи сами передают управление)
-   отсутствие потоков и синхронизации
-   собственный scheduler
-   использование LIFO обеспечивает поведение DFS
-   рекурсия заменена на явное управление задачами
-   корректный порядок обхода за счёт обратного добавления соседей

## Сборка

``` bash
cmake -S . -B build
cmake --build build
```

## Запуск

``` bash
./build/cooperative_dfs
```

## Проверка

В `main` задаётся граф и выполняется обход всех его компонент.

Проверяется:

-   корректность обхода в глубину
-   обработка уже посещённых вершин
-   порядок обхода (соответствие классическому DFS)
