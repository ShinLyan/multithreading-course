# Домашнее задание для лекции по теме "Кооперативная многозадачность"

Реализован обход графа в глубину (DFS) с использованием кооперативной многозадачности на основе корутин C++20.

## Поддерживаемые сущности

- `Task` – корутина, представляющая кооперативную задачу
- `dfs` – кооперативная функция обхода графа в глубину

## Сборка

``` bash
cmake -S . -B build
cmake --build build
```

## Запуск

``` bash
./build/cooperative_dfs
```

## Проверка

В `main` создаются несколько задач DFS, которые выполняются кооперативно.

DFS2: 2
DFS1: 1

DFS1: 2
DFS1: 5
