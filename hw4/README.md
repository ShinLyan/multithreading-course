# Домашнее задание для лекции по теме "Системный вызов futex, устройство кэша, модель памяти C++"

Реализован примитив синхронизации `Mutex` - аналог `std::mutex`, использующий системный вызов `futex`.

Поддерживаются операции:

- `Lock` - захват мьютекса (блокируется при занятом состоянии)
- `Unlock` - освобождение мьютекса

## Сборка

``` bash
cmake -S . -B build
cmake --build build
```

## Запуск

``` bash
./build/futex_mutex
```

## Проверка

В `main` сравнивается поведение стандартного `std::mutex` и собственной реализации `Mutex`

Оба используются для защиты общего счётчика при работе нескольких потоков.

## Полученные результаты

``` text
std::mutex:
counter = 400000
expected = 400000

My Mutex:
counter = 400000
expected = 400000
```
